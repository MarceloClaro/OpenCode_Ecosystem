## 4. Plano de Ação em 3 Rotas

### Rota A — Curto Prazo (1-2 semanas) — Quick Wins
```
1. Adicionar o paradigma Pragmatista via SPEC → 6 categorias destravadas
2. Criar skill de Revisão Sistemática → 2 categorias de método destravadas
3. Executar CognitiveDiversityInjector com 3 artefatos → HI esperado < 0.6
```

### Rota B — Médio Prazo (3-6 semanas) — Expansão Estrutural
```
4. Incorporar Neurociências como domínio cruzado → 10% → 20% cobertura
5. Adicionar Métodos Mistos (sequencial + convergente) → 20% → 40% em métodos
6. Criar skill de Análise Qualitativa (entrevistas) → destrava dados qualitativos
```

### Rota C — Longo Prazo (7-12 semanas) — Maturação
```
7. Implementar todos os 6 paradigmas ausentes → 25% → 100% em paradigmas
8. Pipeline completo de métodos (8 novos) → 20% → 100% em métodos
9. Integração cross-domínio (9 novos domínios) → 10% → 100% em domínios
```

## 10. R35 — Capability Registration Framework (SPEC-080)

**Status:** COMPLETO ✅ | **Testes:** 10/10 PASS | **SPECs totais:** 80 | **CTs totais:** 428/428

### Problema Resolvido

Todas as 58 oportunidades do Potentiality Estimator v2 apresentavam `feasibility="unviable"` com `capabilities_present=[]`. A causa raiz era dupla:

1. **`dna_results={}`** — O MCP server (`ecosystem_capabilities_server.py:190`) passava um dicionário vazio em vez de executar o `PotentialityScanner.extract_dna()`. As capacidades reais dos 64 skills dinâmicos nunca eram transmitidas ao estimador.
2. **`cap in cap_map`** — O método `_check_feasibility` verificava se a capability era uma **key** do dicionário `capability_map`, mas as capabilities estão nos **values** (o dicionário mapeia skill → lista de capabilities). A correção constrói um `set()` de todas as capabilities presentes nos values.

### O que foi feito

| Ação | Detalhe |
|:-----|:--------|
| **SPEC-080** | Capability Registration Framework — 10 CTs, 5 referências teóricas |
| **KEYWORD_TO_CAPABILITY** | Expandido de 36 → 118 entradas (10 dimensões noológicas) |
| **skills_registry.json** | 16 research skills registradas (128 → 144 total) |
| **Fix MCP** | `dna_results={}` → `PotentialityScanner().extract_dna()` |
| **Fix feasibility** | `cap in cap_map.keys()` → `cap in present_capabilities_set` |
